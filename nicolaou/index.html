Η ανάγκη

Οι αγοραστές ψάχνουν ένα έργο πολύ πριν σηκώσουν τηλέφωνο. Αυτό που βρίσκουν online, μια ξεκάθαρη ταυτότητα, μια ιστοσελίδα που τους αφήνει να δουν το έργο σε βάθος, μια παρουσία στα social που δείχνει ένα εργοτάξιο να προχωράει πραγματικά, κάνει μεγάλο μέρος της πώλησης πριν καν μιλήσει η ομάδα σας.

Αυτή η προσφορά καλύπτει τρία κομμάτια που δουλεύουν μαζί: μια ταυτότητα που μπορείτε να βάλετε με σιγουριά σε μια πινακίδα εργοταξίου ή σε μια κάτοψη, μια ιστοσελίδα που ενημερώνει η ίδια σας η ομάδα καθώς προχωρούν τα έργα, και συνεχή παρουσία στα social media και διαφημίσεις που κρατούν αυτή τη ροή αγοραστών ενεργή.

01

Λογότυπο, χρώματα και τυπογραφία, εφαρμοσμένα σε πραγματικά mockups.

Μια ιστοσελίδα χτισμένη γύρω από τα έργα σας, με σύστημα περιεχομένου που τρέχει η ίδια σας η ομάδα.

Μηνιαίο περιεχόμενο και μία ενεργή καμπάνια, χτισμένα για ανθρώπους που θέλουν να αγοράσουν.

Ιστοσελίδα και CMS

€2.850 εφάπαξ

Αυτό είναι το σημείο που θέλω να σταθώ περισσότερο, γιατί η ιστοσελίδα ενός κατασκευαστή ακινήτων δουλεύει διαφορετικά από τις περισσότερες ιστοσελίδες μικρών επιχειρήσεων. Το πιο σημαντικό κομμάτι είναι οι σελίδες Νέων Έργων, αυτές που θα ανεβάζετε εσείς μέσω του CMS, με πλήρη στοιχεία και πίνακα εμβαδών ανά μονάδα. Παράλληλα, η ιστοσελίδα θα φιλοξενεί ένα πορτφόλιο περίπου δέκα ολοκληρωμένων και πωλημένων έργων, ένα εκ των οποίων έχει ακόμη μονάδες προς πώληση αυτή τη στιγμή. Η ιστοσελίδα θα είναι δίγλωσση, Ελληνικά και Αγγλικά.

Χάρτης ιστοσελίδας

Αρχική Σχετικά Έργα · Νέα Έργα Έργα · Ολοκληρωμένα Σελίδα έργου (ανά έργο) Επικοινωνία

Τέσσερις στατικές σελίδες είναι αρκετές εδώ. Δεν πρόσθεσα ξεχωριστή σελίδα Υπηρεσιών, γιατί η ουσία της δουλειάς σας φαίνεται καλύτερα μέσα από τα ίδια τα Έργα παρά από περιγραφές. Αν αναλαμβάνετε και κατασκευή για τρίτους, μια σελίδα Υπηρεσιών θα είχε νόημα, πείτε μου.

Τι δίνει το CMS στην ομάδα σας

  • Σελίδα Νέου Έργου με περιγραφή, τοποθεσία και χάρτη, κατάσταση, ημερομηνία ολοκλήρωσης, 3D renderings, τεχνικά χαρακτηριστικά και κατόψεις σε PDF
  • Πίνακας εμβαδών ανά μονάδα, δωμάτια, μπάνια, εσωτερικό εμβαδόν, βεράντες, κήπο, στάθμευση και αποθήκη, με τη διαθεσιμότητα κάθε μονάδας να αλλάζει ξεχωριστά, διαθέσιμο, πωλήθηκε ή υπό προσφορά
  • Ενότητα Ολοκληρωμένων Έργων, ένα πορτφόλιο περίπου δέκα έργων που δείχνει τη δουλειά σας σε νέους αγοραστές
  • Δίγλωσση δομή, Ελληνικά και Αγγλικά, με εναλλαγή γλώσσας σε κάθε σελίδα
  • Φόρμα ενδιαφέροντος σε κάθε σελίδα έργου, που καταλήγει απευθείας στο email σας
  • Μία συνεδρία εκπαίδευσης για την ομάδα σας, ώστε η προσθήκη ενός νέου έργου να είναι κάτι που κάνετε μόνοι σας
